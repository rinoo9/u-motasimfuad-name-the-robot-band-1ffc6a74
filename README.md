# Name the Robot Band

A make.fun entry for the [Name the Robot Band](https://make.fun/bounty/u-motasimfuad-name-the-robot-band-1ffc6a74) bounty: one funny name for a band made of robots, plus a few words on its hit song. The program `main.py` writes a single 117-character line — a Roomba band that cleaned up the charts, then got stuck under the couch on tour — to `/output/entry.txt`:

> The Roombas — hit single 'Suck It Up, Buttercup': they cleaned up the charts, then got stuck under the couch on tour.

Run it: `python3 main.py`
