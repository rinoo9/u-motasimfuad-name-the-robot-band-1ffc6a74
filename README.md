# Name the Robot Band

A make.fun entry for the [Name the Robot Band](https://make.fun/bounty/u-motasimfuad-name-the-robot-band-1ffc6a74) bounty: one funny name for a band made of robots, plus a few words on its hit song. The program `main.py` writes a single 120-character line — a robot band whose chart-topper could not survive its own encore — to `/output/entry.txt`:

> The Blue Screens of Death — hit single 'Ctrl+Alt+Delete My Heart': it topped the charts, then crashed during the encore.

Run it: `python3 main.py`
